# Studio editor guide (non-technical)

This guide is for everyday content updates in Sanity Studio.

## Where to edit

Use the left sidebar in this order:

1. Home Page
2. Photos
3. Galleries
4. About Page
5. Photographer
6. Site Settings

## Typical updates

### Change the homepage hero

1. Open Home Page.
2. In Hero, update:
- Hero Title
- Hero Description
- Hero Image
- Hero Image Alt Text
- Hero CTA Label / Hero CTA Link
3. Click Publish.

### Choose featured photos on the homepage

1. Open Home Page.
2. Open Featured work.
3. In Featured Photos, add up to 8 photos.
4. Drag to reorder.
5. Click Publish.

If Featured Photos is empty, the website automatically shows recent photos.

### Add a new photo

1. Open Photos.
2. Click Create new.
3. Fill in:
- Image (required)
- Alt Text (strongly recommended)
- Optional: Title, Caption, Location, Date Taken, Gallery
4. Click Publish.

### Create a gallery

1. Open Galleries.
2. Click Create new.
3. Fill in:
- Title (required)
- Optional Description
- Optional Cover Photo
4. Click Publish.

### Update About page

1. Open About Page.
2. Update Heading, Intro Paragraph, Main Text, Portrait Image.
3. Click Publish.

### Update global site settings

1. Open Site Settings.
2. Update Site Title and Site Description.
3. Optionally set Open Graph Image and Favicon.
4. Click Publish.

## Good habits

- Keep image alt text descriptive and plain.
- Keep headings short and clear.
- Publish after each logical change set.
- If something looks wrong, use Discard Changes before publishing.

## Safe editing notes

- Home Page, About Page, Photographer, and Site Settings are single documents.
- Studio is configured to avoid accidental duplicates of these single pages.
